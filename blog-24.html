Philosophy

One file. One command. No Kubernetes, no Terraform, no complexity.

The docker-compose.yml

version: '3.8'

services:
  ollama:
    image: ollama/ollama:latest
    volumes:
      - ollama:/root/.ollama
    ports:
      - "11434:11434"
    restart: unless-stopped

  n8n:
    image: n8nio/n8n:latest
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=changeme
    volumes:
      - n8n:/home/node/.n8n
    ports:
      - "5678:5678"
    restart: unless-stopped

  postgres:
    image: postgres:15-alpine
    environment:
      - POSTGRES_USER=ai
      - POSTGRES_PASSWORD=changeme
      - POSTGRES_DB=aidb
    volumes:
      - postgres:/var/lib/postgresql/data
    restart: unless-stopped

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
    restart: unless-stopped

  watchtower:
    image: containrrr/watchtower
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    command: --interval 86400
    restart: unless-stopped

volumes:
  ollama:
  n8n:
  postgres:

Why This Works

  • Ollama — dead simple model management. One command to pull any model.
  • n8n — visual workflow builder. Connect AI to everything without code.
  • PostgreSQL — reliable data store. Handles everything from chat history to vector search.
  • nginx — reverse proxy + SSL. Single entry point for all services.
  • Watchtower — auto-updates. Security patches apply themselves.

Resource Usage

On a 2-core, 2GB VPS:

  • Idle RAM: ~800MB
  • With 1 model loaded: ~1.4GB
  • Peak (model swap): ~1.8GB (uses swap)
